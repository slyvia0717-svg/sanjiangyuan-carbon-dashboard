# 成果说明

## 历史阶段

2005—2025年统一300米序列显示，研究区碳储量由1041.39 Mt C下降至1019.97 Mt C，净减少21.42 Mt C。变化并非单向：2010—2015有所恢复，2015—2020出现显著下降，2020—2025再次回升。

2015—2020是历史序列中最值得关注的异常阶段。内部核查显示，草地转裸地是主要负向贡献，裸地转草地形成部分抵消；部分变化在2025年发生反转，因此解读时需要同时考虑分类波动与真实地表变化。

## 未来BAU情景

模型预测2030年碳储量约1013.10 Mt C、2035年约1006.49 Mt C。与2025年相比，2035年累计减少约13.48 Mt C。

这些结果表示：若历史转移规律、邻域效应和地形约束延续，碳储量可能继续缓慢下降。结果未纳入未来气候、道路、居民点扩张或保护政策变化，不能解释为确定性预报。

## 空间结果

碳变化集中在草地、裸地、水体和冰雪交错区域。主要正负贡献往往同时出现，总量变化是多个相反转移过程抵消后的净结果。
