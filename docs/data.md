# 数据来源与目录约定

## 输入数据

### 研究区边界

研究区由黄河源园区、长江源园区和澜沧江园区三个Shapefile组成。原始矢量经文件完整性、CRS、属性与几何有效性检查后合并为统一边界。

### 土地覆盖

历史土地覆盖采用CLCD五期数据：2005、2010、2015、2020和2025。原始数据为30米栅格；历史精细分析保留30米结果，历史—未来统一比较则通过10×10窗口众数聚合至300米。

### 地形

地形变量采用Copernicus DEM GLO-30。下载与研究区相交的33个1°×1°瓦片，生成与分析网格对齐的高程、坡度和坡向。

### 碳密度

每个土地覆盖类别对应地上、地下、土壤和枯落物四个碳库。`parameters/`包含：

- 陆地基准方案；
- 纳入湖泊底泥碳的敏感性方案；
- 对冰雪/裸地合并类别进行字面解释的敏感性方案；
- 参数对应关系和情景汇总。

## 推荐的本地数据结构

```text
data/
├── raw/
│   ├── boundary/
│   ├── clcd/
│   └── dem/
├── interim/
└── processed/
```

## 未提交GitHub的数据

原始CLCD、DEM瓦片、30米裁剪栅格、完整InVEST工作区和训练模型文件体积较大，不应直接提交普通Git仓库。仓库仅提供轻量边界、参数表、汇总表、成果图和Dashboard展示数据。

## 尺度说明

2005—2035连续比较统一使用300米网格。不得把30米历史碳储量总量与300米未来预测总量直接拼接，因为分类聚合会改变地类组成和碳量估计。
