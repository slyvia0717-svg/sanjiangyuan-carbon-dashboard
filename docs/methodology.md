# 方法与质量控制

## 1. 边界处理

验证三个园区Shapefile的核心组成文件、坐标系统、属性表、闭合环、自相交和面积，随后合并为统一研究区边界。边界总面积与约123,100 km²的参考范围接近。

## 2. 土地覆盖预处理

五期CLCD统一投影、裁剪范围、像元对齐、NoData和类别编码。历史—未来统一分析采用300米众数聚合，并以共同掩膜保证七期有效像元完全一致。

## 3. 历史变化分析

计算各期地类面积、相邻期转移矩阵、2005—2025长期变化，以及2015—2020异常变化的空间稳定性、反转比例、斑块规模和碳贡献。

## 4. 土地覆盖预测

训练时期为2005→2010、2010→2015和2015→2020，2020→2025完全留作时间外验证。模型使用Extra Trees，并结合：

- 当前与上一期土地覆盖；
- 近期是否发生变化；
- 3×3和11×11邻域中九类土地覆盖比例；
- 高程、坡度、坡向；
- 归一化空间位置。

为缓解类别不平衡，训练采用分层抽样和样本权重。预测阶段按各起始地类的历史平均变化率分配变化配额，再递推生成2030和2035年BAU情景。

## 5. InVEST碳储量

七期土地覆盖均使用同一套碳库参数，通过InVEST 3.20.2正式计算。未开启经济价值模块。碳变化由两期碳密度栅格相减，并根据300米像元面积换算为总量。

## 6. 质量控制

- 七期网格、投影、行列数和共同掩膜一致；
- 每期有效像元1,370,478个，有效面积123,343.02 km²；
- 分类编码限定为1—9；
- InVEST日志无ERROR或CRITICAL；
- 七期InVEST结果与独立碳密度映射逐像元一致；
- 最大绝对差约0.000015 Mg C/ha，仅为浮点精度误差；
- 三园区汇总面积与碳储量严格回算至整个研究区。
