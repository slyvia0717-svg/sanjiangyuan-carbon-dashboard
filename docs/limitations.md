# 局限性

1. **预测能力有限。** 变化识别F1为0.345，说明模型可识别部分变化，但对具体变化位置仍存在较大不确定性。
2. **总体精度易被类别不平衡误导。** 约96%的像元相邻时期不变，“全部不变”基线总体精度略高于预测模型。
3. **驱动变量不完整。** BAU模型未加入未来气候、道路、居民点和政策情景。
4. **空间尺度经过聚合。** 300米众数聚合适合区域情景分析和网页展示，但会损失30米小斑块信息。
5. **碳密度是类别常数。** InVEST在同一地类内部使用固定碳密度，无法表达土壤、植被年龄和退化程度的连续差异。
6. **敏感类别依赖假设。** 水体底泥碳以及冰雪/裸地解释会显著影响局部结果，因此主结果与敏感性方案分开呈现。

未来改进可加入气候和人类活动驱动、空间分块交叉验证、多个机器学习模型集成，以及基于实测数据的碳密度校准。
