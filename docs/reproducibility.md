# 复现指南

## 环境

- Python 3.9或更高版本
- InVEST 3.20.2
- `requirements.txt`中的Python依赖

## 运行顺序

1. 按`docs/data.md`准备CLCD、边界和DEM数据。
2. 建立碳密度参数表。
3. 生成与CLCD网格一致的DEM、坡度和坡向。
4. 训练土地覆盖模型，并用2020—2025进行独立验证。
5. 生成2030和2035 BAU预测。
6. 统一七期300米土地覆盖及共同掩膜。
7. 使用InVEST运行七期碳储量。
8. 生成统一统计表、变化栅格和成果图。
9. 导出Dashboard轻量地图与JSON数据。

核心脚本按上述流程位于`scripts/`。脚本默认采用仓库根目录下的标准路径，实际使用时应根据本地文件位置调整配置。

## 验证要求

复现结果至少应满足：七期掩膜一致、分类值合法、InVEST日志无严重错误、独立计算与InVEST逐像元差异处于浮点误差范围、园区统计能够回算至全研究区。
